# 构建与安装（不上架 App Store）

本项目只产出一个 App：**GuitarHub**，装在 iPhone 上。

## 0. 先决条件：iOS App 必须用 macOS 编译

这不是本项目的选择，而是 Apple 的平台限制：iOS 的编译器、SDK、签名工具只随 Xcode 发布，Xcode 只运行在 macOS 上。
所以「编译成 .app/.ipa」这一步，必须有 macOS；「安装/续签」这一步可以在 Windows 上完成（Sideloadly / AltServer）。

没有 Mac、也不用云 Mac 时，实际只有三条路：

| 路线 | 需要 | 一次性成本 | 后续 |
|---|---|---|---|
| A. 借/买一台 Mac | macOS 13+、Xcode 15（或 macOS 12 + Xcode 14.2） | 借用 0 元；二手 M1 Mac mini 约 ¥2000–3000 | 改代码随时可编译；Windows 上续签 |
| B. 不用 Apple 工具链（ESP32 + 网页界面） | ESP32-S3 开发板约 ¥50 | 低于 ¥100 | 重新实现一遍，且失去 KORG 控制 |
| C. 云 Mac / CI | GitHub 账号 | 免费（私有库每月 2000 分钟） | 全自动出 IPA，但本质仍是云 Mac |

下面第 1 节是路线 A，第 5 节是路线 B 的概要。

## 1. 有 Mac：本地构建

要求：macOS 13+、Xcode 15+、[XcodeGen](https://github.com/yonaskolb/XcodeGen)。

```bash
brew install xcodegen
cd ios
xcodegen generate
open GuitarHub.xcodeproj
```

在 Xcode 里：

1. 选中 `GuitarHub` target → Signing & Capabilities → 选你的 Team（免费 Apple ID 也行），
   Bundle Identifier 改成一个**全球唯一**的值，例如 `com.yourname.guitarhub`。
2. iPhone 用数据线连电脑，选设备 → Run。
3. 首次运行后，在 iPhone「设置 → 通用 → VPN与设备管理」里信任开发者证书。
4. iOS 16+ 需要在「设置 → 隐私与安全性 → 开发者模式」打开开发者模式并重启。

## 2. 没有 Mac：GitHub Actions 出未签名 IPA

仓库自带 `.github/workflows/ios.yml`：push 到 `main` 或手动触发，会自动：

1. `xcodegen generate`
2. `xcodebuild` 以 `CODE_SIGNING_ALLOWED=NO` 编译
3. 打包成 `GuitarHub-unsigned.ipa` 并作为 artifact 上传

然后在 iPhone 上用 **SideStore** 或 **AltStore** 签名安装。

### SideStore / AltStore 现状（2026）

| 方式 | 有效期 | 限制 |
|---|---|---|
| 免费 Apple ID | **7 天**，到期需重签 | 最多 3 个自签 App、10 个 App ID / 7 天；需定期连一次 |
| 付费开发者账号（$99/年） | **1 年** | 最多 100 台设备；可用 Ad Hoc 分发 |

- SideStore 需要配对一台电脑做一次“安装引导”，之后可以纯 Wi-Fi 刷新。
- 重签不会丢数据（App 容器保留），但**不要删除 App**，删除即清空预设库。

参考：<https://sidestore.io>、<https://altstore.io>

## 3. 首次配置（iPhone）

1. 打开 App → **设置 → 设备配置**，确认能看到 `Spark Mini` 与 `Pulze Mini` 两份配置。
2. **设备**页 → 搜索 → 点你的音箱连接。
3. Spark：连接后自动读取当前音色，演出页应显示音色名与 7 个模块。
4. **踏板**页 → 搜索并连接蓝牙 MIDI 踏板。
5. **音源**页：Module 打开 Background Audio 并在后台运行，MIDI 输入选 `GuitarHub`。
   如果列表里没有这个端口，就跳过这一步——音箱与踏板功能不受影响。

## 4. 常见问题

| 现象 | 排查 |
|---|---|
| 搜索不到 Spark | 确认音箱没被官方 Spark App 占着；蓝牙已开；音箱处于可连接状态（开机后未连其他设备） |
| 连上但读不到音色 | 看“设备 → 音色与调试 → 原始收发”，若没有 `F0 01 …` 回包，可能是固件命令基址不同（见协议笔记） |
| 改参数没反应 | Spark 必须知道当前模块名；先“读取”一次音色 |
| Pulze 收不到 | 确认 Pulze 的蓝牙没连官方 Editor；BLE MIDI 同一时间只接受一个中心 |
| Module 收不到 PC | 确认 Module 的 MIDI 输入选的是 `GuitarHub`；若列表里根本没有它，说明 Module 不接受虚拟端口，改用本 App 手动管理音色 |
| 踏板一脚触发两次 | 不要同时在系统设置里把踏板配成 BLE MIDI；只让 App 直连 |
| 7 天后打不开 | 免费签名过期，用 SideStore 重签，不要删除 App |
