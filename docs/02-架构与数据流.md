# 架构与数据流

## 1. 分层

```
┌──────────────────────────── UI（SwiftUI） ────────────────────────────┐
│ 演出大屏 │ 音源页 │ 设备页（含原始收发） │ 踏板映射 │ 设置          │
└───────────────▲──────────────────────────────▲───────────────────────┘
                │ ObservableObject             │
┌───────────────┴──────────────┐  ┌────────────┴───────────────────────┐
│ AmpDevice（每台设备一个）    │  │ KorgController / PedalRouter        │
│ 状态、预设库、召回/推送逻辑  │  │ 音色表、PC 发送、踏板动作分发       │
└───────────────▲──────────────┘  └────────────▲───────────────────────┘
                │ DeviceCodec                  │ MIDIMessage
┌───────────────┴──────────────┐  ┌────────────┴───────────────────────┐
│ SparkCodec │ MIDICodec      │  │ MIDIService（CoreMIDI 虚拟端口）    │
│ 私有协议   │ 通用 CC/PC     │  │ 虚拟源 "GuitarHub" → Module         │
└───────────────▲──────────────┘  └────────────▲───────────────────────┘
                │ Data                         │
┌───────────────┴──────────────────────────────┴───────────────────────┐
│ BLESession（扫描/连接/GATT/分片写入） │ BLEMIDIPedal（踏板直连）       │
└──────────────────────────────────────────────────────────────────────┘
```

使用模型：**三选一，互斥**。`DeviceHub.target`（`.spark` / `.pulze` / `.korg`）决定当前只有哪台设备参与；
切换目标时，其余设备主动断开，踏板组切到同名的那一组。因此任意时刻只有「目标设备 + 踏板」两条 BLE 连接。

要点：

- **UI 只认 `AmpDevice`**，不关心设备是 Spark 还是 Pulze。
- **`DeviceCodec` 是唯一的协议翻译层**：输入输出都是统一语义（模块 id、显示单位 0…100）。
- **`BLESession` 不认识任何设备**：只负责字节流。新增设备时它通常不用改。

## 2. 一次“踩钉切混响”的完整路径

```
踏板 ──BLE MIDI──▶ BLEMIDIPedal ──MIDIMessage──▶ PedalRouter
                                                   │ 查当前踏板组
                                                   ▼
                                       AmpDevice.toggleModule("reverb")
                                                   │ 乐观更新 UI
                                                   ▼
                                       SparkCodec.setModule("reverb", true)
                                                   │ 找槽位 6 的当前模块名
                                                   ▼
                                  SparkProtocol.frame(cmd:0x01, sub:0x15, …)
                                                   ▼
                                       BLESession.sendChunked(20B/包)
                                                   ▼
                                              Spark Mini
```

反向：音箱被旋钮改动 → `FFC2` 通知 → `SparkProtocol.Decoder` 重组 → `SparkCodec` 发 `.paramChanged` → `AmpDevice` 更新 UI 并写回本地预设库。

## 3. 设备配置（Profile）驱动

每台设备是一份 JSON（`ios/GuitarHub/Resources/Profiles/*.json`），结构：

```json
{
  "id": "spark-mini",
  "name": "Spark Mini",
  "transport": {
    "kind": "ble", "codec": "spark",
    "serviceUUIDs": ["FFC0"],
    "namePrefixes": ["Spark MINI"],
    "chunkSize": 20, "chunkIntervalMs": 8
  },
  "capabilities": { "stateReadback": true, "presetCount": 4 },
  "modules": [
    { "id": "reverb", "name": "混响", "slot": 6,
      "bypass": { "kind": "sparkSlot", "slot": 6 },
      "params": [
        { "id": 0, "name": "强度",
          "mapping": { "kind": "sparkParam", "slot": 6, "param": 0 } }
      ] }
  ]
}
```

- 所有字段都可省略，缺省有默认值（`Models.swift` 里的宽容解码）。
- `transport.codec` 决定用哪个编解码器；`template` 为后续“抓包即配置”预留。
- 用户可以把新 JSON 放进「文件」App → `我的 iPhone/吉他中枢/Profiles/`，App 内点“重新加载设备配置”，**无需重编译**。
  （Info.plist 已开启 `UIFileSharingEnabled`，所以这个目录在「文件」里可见。）

## 4. 预设库：谁是真身？

| 设备 | 真身 | 原因 |
|---|---|---|
| Spark | 音箱 | 能读回完整音色；App 只在本地缓存一份便于离线查看 |
| Pulze | App 本地 | 官方 MIDI 不能读回；召回时先用本地快照更新 UI，再把开关/音量整包推给设备 |

`AppStore` 把每台设备每个预设的模块状态存成 `AmpSnapshot`，JSON 落盘在
`Application Support/GuitarHub/store.json`，写操作 0.6 秒防抖。

## 5. KORG 的投递路径

```
KorgController ──▶ MIDIService.send(PC) ──▶ 虚拟源 "GuitarHub"
                                            └─▶ 后台 Module（若它接受虚拟端口）
```

只有这一条路。若 Module 的 MIDI 输入里没有 `GuitarHub`，`KorgController` 的发送不会报错，只是没人接收；
此时 App 的音箱与踏板功能完全不受影响，音源页仍可作为“节目单大字屏 + 手动跟手切换”使用。

## 6. 文件地图

| 文件 | 职责 |
|---|---|
| `Core/Models.swift` | 配置模型、状态模型、编解码器协议、宽容解码 |
| `Core/ProfileStore.swift` | 加载包内 + 文档目录的设备 JSON，校验并收集问题 |
| `Core/AmpDevice.swift` | 单设备状态、预设召回/整包推送、事件归并 |
| `Core/DeviceHub.swift` | 全局装配：设备、MIDI、KORG、踏板、网络桥 |
| `Core/PedalRouter.swift` | 踏板消息 → 动作（含踏板组切换） |
| `BLE/BLESession.swift` | 通用 BLE 中心：扫描、GATT、分片写、重连、GATT dump |
| `BLE/BLEMIDI.swift` | BLE MIDI 包的解包/封装 |
| `BLE/BLEMIDIPedal.swift` | 踏板直连（不经系统 MIDI，避免重复触发） |
| `Codecs/SparkProtocol.swift` | Spark 分帧/打包/解包/预设解析 |
| `Codecs/SparkCodec.swift` | Spark 命令映射与状态回填 |
| `Codecs/MIDICodec.swift` | 通用 CC/PC 映射 |
| `MIDI/MIDIService.swift` | CoreMIDI 客户端、虚拟源、端点枚举、直连 Module |
| `MIDI/KorgController.swift` | 音色表、PC 发送 |
| `UI/*` | 演出大屏、音源、设备调试、踏板映射、设置 |
